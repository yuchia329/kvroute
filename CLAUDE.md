# kvroute

A KV-cache-aware inference router fronting six single-GPU vLLM replicas. The deliverable is a
measured comparison of routing policies. See `CONTEXT.md` for the domain glossary and `idea.md`
for the project spec.

See `docs/agents/issue-tracker.md`.
